# B570 自平衡循跡車

這是我們這組做的兩輪自平衡小車，主控用 STM32F103C8。要做到的事有三個：車子自己站著不倒、沿地上的黑線走、開上蹺蹺板後能爬上去再控制好下坡別衝出去。

這三件事其實會互相打架——爬坡需要一直往前推，但循跡又怕速度太快過彎衝過頭，所以參數調了很久。調的過程跟踩過的坑都記在 [DEBUG.md](DEBUG.md)，程式裡每個參數旁邊也都有寫註解。

## 硬體接線

板子是 STM32F103C8 + S28A 轉接板，接法如下：

- **MPU6050（姿態感測）**：軟體 I²C，SCL/SDA 接 PB8/PB9；INT 腳接 PA0，用 EXTI0 下降緣觸發。
  - （一開始 INT 接 PA12 一直沒反應，後來改 PA0 才正常。）
- **馬達（TB6612）**：PWM 走 TIM1，PWMA=PA8、PWMB=PA11；方向腳 AIN1/AIN2=PB14/PB15、BIN1/BIN2=PB13/PB12。
- **編碼器**：左輪 TIM3（PA6/PA7）、右輪 TIM4（PB6/PB7），用來量輪速給速度環。
- **紅外循跡**：三顆數位感測器，左中右分別接 PB1 / PA1 / PA2，碰到黑線輸出低電位，腳位開內部上拉。
- **OLED**：軟體 SPI（PB3/PA15/PB5/PB4），顯示角度跟目前模式。
- **按鍵**：PA5，按一下切換馬達開 / 關。
- **UART**：115200，可以把角度、左右編碼器值丟到電腦用 DataScope 看波形。

## 程式怎麼跑的

MPU6050 的 DMP 每秒丟 200 次姿態，每次都觸發一次 PA0 中斷。我們在中斷裡每兩次才真正算一次控制，所以實際控制頻率是 100Hz（dt = 10ms）。一個控制週期大概做這些：

1. `Get_Angle()`：拿 Pitch 傾角和角速度。
2. `Velocity()`：速度環（PI，吃編碼器）。站著跟爬坡用的 Ki/Kp 不一樣，爬坡要更大的推力才上得去。
3. `Balance()`：直立環（PD，傾角 + 角速度），這是讓車子站著的核心。
4. 循跡：三顆紅外算出偏差，做 PD 轉向修正。
5. 模式判斷：依角度和循跡狀態自動在 BAL / TRACK / CLIMB / DOWN 之間切換。
6. `Set_Pwm()`：把上面算出來的合成左右輪 PWM，最後加上馬達死區補償（PWM 太小馬達根本不會動）。

四種模式，OLED 上會顯示：

- **BAL**：純站著平衡，不循跡。
- **TRACK**：平地循跡，速度環增益調得保守一點。
- **CLIMB**：偵測到車子持續往前仰一陣子，判定在爬坡，加大速度環推力。
- **DOWN**：過了蹺蹺板頂點、角度突然往下掉，進下坡模式，關掉循跡並壓住速度，免得衝下去翻車。

## 編譯 / 燒錄

用 Keil MDK-ARM（µVision5），另外要先用 Pack Installer 裝 STM32F10x 的 Device Family Pack。

1. 開 `USER/Minibalance.uvprojx`。
2. 確認晶片是 STM32F103C8。
3. 按 F7 編譯，再用 ST-Link（SWD）接上板子，F8 燒進去。

`OBJ/`、`*.uvopt`、`*.uvgui` 那些是編譯產物跟個人的 IDE 設定，會自己重新產生，所以丟進 `.gitignore` 沒上傳。

## 操作

1. 開機時馬達預設是關的（`Flag_Stop = 1`）比較安全，OLED 會亮、顯示角度。
2. **先抓中點**：用手扶著車子到它真的平衡的位置，看 OLED 上的 Angle 是多少，把 `control.h` 裡的 `Middle_angle` 改成那個值。這步沒抓好車子會一直往一邊倒。
3. 按一下 PA5，馬達開，車子開始自己站。
4. 放到黑線上就會開始循跡。如果你的感測器是碰到線輸出高電位，把 `ir_tracker.h` 的 `IR_BLACK` 改成 1。
5. 蹺蹺板直接開上去就好，爬坡跟下坡會自己切模式。
6. 車子倒超過 ±40° 會自動斷馬達（`Turn_Off`），不會繼續暴衝。
7. 要調參數的話：平衡和蹺蹺板的門檻在 `control.h`，循跡的轉向、過彎、失線處理在 `ir_tracker.h`，每個值旁邊都寫了是幹嘛的、要往哪邊調。

## 版本

我們是邊做邊測，分成幾個階段（對應 git 的 tag）：

- `v0.1` 靜態平衡 — 先讓它能站著不倒。
- `v0.2` 加循跡框架 — 移動時還是會平衡，循跡先把架構搭起來，還沒調通。
- `v0.3` 平地循跡 — 可以穩定沿線走了。
- `v0.4` 上坡 — 加大推力，爬得上蹺蹺板。
- `v1.0` 上下坡 — 蹺蹺板上下坡自動切換、下坡控速，完整功能。

每個階段的細節看 commit 紀錄跟 DEBUG.md。
